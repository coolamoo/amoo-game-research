# 参数速查

一页看完三个原型的可调数值。**改代码后请同步改这里**，不要留两份不一致的数。

## 一、`pixel-racer.html`（2D，手感基准）

| 参数 | 值 | 含义 | 调大的效果 |
|---|---|---|---|
| `speed0` | 300 | 初速 | 起步更快 |
| `speedMax` | 980 | 最高速 | 后段更疯 |
| `speedGain` | 10 | 每秒增速 | 到顶更快 |
| `steerAccel` | 1500 | 转向加速度 | 打方向更贼 |
| `latMax` | 300 | 横向速度上限 | 能横移得更远 |
| `gripNormal` | 9 | 正常抓地 | 越大小幅滑不了，车"贴地" |
| `gripDrift` | 2.4 | 漂移抓地 | 越小滑得越狠 |
| `yawMax` | 0.42 | 最大偏航角（视觉倾斜） | 车身倾斜更夸张 |
| `driftMinSpeed` | 380 | 触发漂移的最低速 | 低速也能甩 |
| `driftRate` | 0.55 | 漂移充能速率 | 氮气来得更快 |
| `nitroPerDrift` | 0.34 | 漂移→氮气转化率 | 一次漂移换更多氮气 |
| `nitroTime` | 2.0 | 氮气持续秒数 | 爽感延长 |
| `nitroBoost` | 1.55 | 氮气倍率 | 更快 |
| `nitroMin` | 0.25 | 触发氮气的最低储量 | 更容易放出 |
| `spawnStart` / `spawnMin` | 1.0 / 0.42 | 敌车生成间隔（秒），随时间收紧 | 越小越挤 |
| `skidMax` | 320 | 刹车痕数量上限（环形复用） | 拖尾更长 |

**手感的核心就两个数**：`gripNormal` 与 `gripDrift` 的落差。9 : 2.4 ≈ 3.75 倍，落差越大漂移越明显。

## 二、`road-racer-3d.html`（3D，真实量纲）

单位是米与米每秒，这是三版里唯一有物理量纲的。

| 参数 | 值 | 含义 |
|---|---|---|
| `roadW` / `laneCount` | 14 / 2 | 路宽（米）、车道数 |
| `accel` | 9.5 | 油门加速度 m/s² |
| `brake` | 16 | 刹车减速度 m/s² |
| `engineBrake` | 2.2 | 松油门自然减速 |
| `vMax` | 78 | 最高车速 m/s ≈ 280 km/h |
| `steerMax` | 0.9 | 最大前轮转角（弧度，≈51.6°） |
| `gripLat` | 26 | 横向抓地 |
| `carLen` / `carWid` | 4.4 / 1.85 | 车身尺寸（米） |
| `camDist` / `camHeight` | 7.4 / 2.15 | 相机距离与高度 |
| `traffic` / `treeCount` | 6 / 26 | 交通车、树木数量 |
| `fogNear` / `fogFar` | 60 / 260 | 雾起止距离（米） |

## 三、二维 → 三维的换算（未验证，待补）

目前 2D 与 3D 是两套独立参数，没有做映射。要做的话先回答：

- 2D 的 `speedMax 980`（像素/秒）对应 3D 的 `vMax 78`（米/秒），比例取决于屏幕 PPI 与镜头焦距，需要实测标定。
- 2D 的 `gripNormal 9` 没有物理单位，3D 的 `gripLat 26` 是 m/s²，两者不是同类量，只能靠"手感对齐"主观匹配。

这条换算关系一旦定下来，写进 `docs/param-map.md`（尚未创建）。
