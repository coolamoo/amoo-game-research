# 术语表

| 术语 | 在这个项目里指什么 | 常见误解 |
|---|---|---|
| 抓地力（grip） | 一个抽象数值，决定车横向滑动的阻力。2D 版里 `gripNormal 9`、`gripDrift 2.4` | 不是真实轮胎摩擦系数，没有单位 |
| 漂移 | 抓地力下降后车体自然滑动，玩家只控方向，不做"手刹"动作 | 不是按住某个键就触发 |
| 氮气 | 漂移积累的能量，达阈值后可释放 | 不是捡道具获得 |
| `vMax` | 最高车速，单位 m/s | 不是 km/h；78 m/s ≈ 280 km/h |
| ACES | `ACESFilmicToneMapping`，色调映射算法，让高光不发白、颜色不发灰 | 不是滤镜，是渲染管线的一步 |
| 雾（Fog） | `THREE.Fog(色, 近, 远)`，远景按距离淡入背景色 | 不等于"起雾"特效；这里用来做近实远虚 |
| CanvasTexture | 用 2D 画布现画贴图，再贴到 3D 物体上 | 不是后处理特效 |
| Bloom | 泛光后处理，能让亮的更亮 | 这个项目**没用**，霓虹感靠 CanvasTexture |
| GLB | 二进制 glTF，模型与贴图打包成一个文件 | 不是压缩包，不能被 zip 打开 |
| LOD | 按距离切换不同精度的模型 | 本项目的模型还没做 LOD |
| 三角面（triangle） | 3D 模型的最小面片，衡量模型复杂度 | 不是"面数=顶点数" |
| Draco | glTF 的几何压缩扩展 | 会引入解码开销，本项目未使用 |
| 环形复用 | 刹车痕只保留固定数量，旧的回收给新的用（`skidMax 320`） | 不是无限拖尾 |
| 近实远虚 | 近处细节清楚、远处简化并淡化 | 不只是"加模糊"，还包括降细节与暖气调 |
